# Fish Resort — QR-меню

Веб-приложение цифрового меню для ресторана Fish Resort. Предназначено для просмотра через QR-код: гости открывают меню на телефоне, ищут блюда и переходят по категориям.

---

## Возможности

- **Hero-блок** — баннер с фото, названием и кратким описанием ресторана
- **Поиск по меню** — фильтрация по названию, описанию и составу блюд
- **Категории** — липкая навигация (Салаты, Шашлык, Горячие блюда, Напитки, Горячие напитки) с прокруткой к выбранному разделу
- **Карточки блюд** — фото, название, цена (₸), описание, состав, вес (если есть)
- **Кнопка «Наверх»** — появляется при прокрутке вниз
- **Адаптивная вёрстка** — удобно на мобильных и планшетах

## Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Приложение будет доступно по адресу **http://localhost:5173/**.

### Сборка для продакшена

```bash
npm run build
```

Артефакты появятся в папке **`dist/`**.

### Просмотр собранной версии

```bash
npm run preview
```

### Запуск тестов

```bash
npm run test
```

Режим с отслеживанием изменений (watch):

```bash
npm run test:watch
```

## Тесты

Покрыты тестами:

- **ImageWithFallback** — отображение картинки и показ запасного варианта при ошибке
- **Hero** — заголовок, описание, поле поиска и вызов `onSearchChange`
- **Navbar** — отображение категорий и вызов `onCategoryChange` по клику
- **MenuCard** — название, цена, описание, состав, вес, изображение
- **App** — рендер заголовка и меню, фильтрация по поиску, пустой результат, переход к категории «Напитки»

Запуск:

```bash
npm run test
```
